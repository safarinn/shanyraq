**Начните с `START_HERE.md`: там 6 простых шагов разбора кода и ответы для защиты. Затем откройте `CODE_GUIDE.md`.**

В этой версии формы и основные блоки находятся прямо в HTML. JavaScript разделён по страницам, код развернут на строки и снабжён русскими комментариями. Вёрстка сделана на Flexbox, без CSS Grid.

# Продажа и аренда недвижимости

Готовый учебный многостраничный сайт по требованиям Web Programming Project.
Интерфейс на русском языке. Собственный зелёный дизайн; квартиры, дома и коммерческая недвижимость Казахстана. Название shanyraq.kz — бренд проекта, домен не зарегистрирован и сайт не опубликован.

## Быстрый запуск на Mac / Linux

Нужен Python 3.9 или новее с SQLite (в стандартной поставке Python). Внешние библиотеки и npm не нужны.

1. Распакуйте ZIP.
2. Откройте терминал в папке `shanyraq`.
3. Выполните:

```bash
python3 server.py
```

4. Откройте в браузере **http://127.0.0.1:8000**.
5. Для остановки нажмите `Ctrl+C` в терминале.

Также можно выполнить `bash start.sh` в папке проекта.

Если порт занят:

```bash
python3 server.py --port 8080
```

Откройте http://127.0.0.1:8080.

## Windows

Откройте терминал в папке проекта и выполните:

```powershell
py server.py
```

Или запустите `start.bat`. Адрес сайта тот же: http://127.0.0.1:8000.

Если команда Python не найдена, установите Python 3 с официального сайта https://www.python.org/downloads/ и повторите запуск. На Windows при установке отметьте `Add Python to PATH`.

**Не открывайте index.html двойным щелчком и не используйте VS Code Live Server:** для регистрации, SQLite и заявок необходим `server.py`. HTML, CSS и JavaScript находятся в папке `public`.

## Возможности

- 12 HTML-страниц с общей навигацией и футером.
- Регистрация: имя, фамилия, email, телефон, пароль, подтверждение.
- Уникальный email, проверка формата email, длины пароля, совпадения паролей и телефона.
- Вход, выход, защищённый личный кабинет, редактирование профиля.
- 8 начальных объявлений: Алматы, Астана, Шымкент.
- Продажа / аренда; квартиры / дома / коммерческая недвижимость.
- Поиск по названию и адресу, фильтры города, типа и максимальной цены.
- Сортировка по цене и новизне, сброс фильтров, состояние «ничего не найдено».
- Детальная страница объекта, характеристики, описание.
- Избранное сохраняется для каждого пользователя в базе.
- Запись на просмотр: будущая дата, время, телефон, комментарий.
- Подтверждение с номером заявки; история и отмена заявки в профиле.
- Админка: просмотр пользователей, создание / чтение / изменение / удаление объявлений, просмотр заявок и изменение статусов.
- При удалении объявления история заявки сохраняет название объекта.
- Адаптивные сетки для компьютера, планшета и телефона; мобильное меню.
- Все изображения — локальные SVG-иллюстрации, созданные для проекта. Интернет для работы не нужен.

Кнопка «Разместить» открывает панель добавления для администратора, для остальных — страницу с описанием размещения. По требованиям управление объектами выполняет администратор.

## Данные и устройство

- **Frontend:** semantic HTML5, CSS3 (Flexbox, media queries, transitions), vanilla JavaScript (DOM, события, формы, fetch).
- **Backend:** Python, стандартные `http.server` и `sqlite3`.
- **Database:** `data/shanyraq.sqlite3`, создаётся автоматически при первом запуске.
- Таблицы: `users`, `properties`, `favorites`, `bookings`.
- Пароли: PBKDF2-HMAC-SHA256, индивидуальная соль, 200 000 итераций.
- Вход: случайный токен в HttpOnly / SameSite cookie, серверные сессии, проверка CSRF-токена при изменениях.
- Запросы SQLite параметризованы; роль администратора проверяется на сервере.
- Пользовательские тексты экранируются при отображении.

Данные сохраняются после перезапуска. Сессии хранятся в памяти: после перезапуска сервера войдите снова. Для сброса учебных данных остановите сервер и удалите папку `data`. Следующий запуск создаст базу и исходные объявления заново.

В проекте нет реальных владельцев, платежей, отправки писем или звонков. Заявки обрабатываются только внутри учебного сайта. Локальный сервер предназначен для демонстрации задания; для публичного сервиса потребуются производственный сервер, HTTPS и дополнительные меры эксплуатации.

## Проверки

В папке проекта:

```bash
python3 tests/test_app.py
```

Тесты запускают отдельный сервер на свободном порту и используют временную базу. Основные данные не изменяются. Проверены регистрация и 6 ошибок ввода, уникальный email, неправильный вход, права доступа, профиль, избранное, запись / дублирование / отмена просмотра, статусы, CRUD, история после удаления объекта, CSRF, выход и существование страниц / ресурсов.

Синтаксис всех JavaScript-файлов проверен. Логика поиска, фильтров и сортировки также проверяется без браузера:

```bash
node tests/test_frontend.js
```

Node требуется только для этой дополнительной проверки, не для запуска сайта.

Автоматическая проверка в реальном браузере не выполнялась. Для демонстрации откройте сайт на компьютере и в мобильном режиме браузера (390 px и 768 px).

### Сценарий защиты задания

1. Откройте регистрацию. Попробуйте неверный email, короткий пароль, несовпадающие пароли, пустое имя, неверный телефон, затем повторную регистрацию существующего email.
2. Создайте аккаунт и выйдите. Покажите ошибку неверного пароля, затем войдите правильно.
3. В каталоге переключите продажу / аренду, город и тип, задайте цену и поиск. Покажите сортировку и пустой результат.
4. Добавьте объект в избранное, обновите страницу, откройте избранное.
5. В деталях выберите будущую дату и время. Отправьте заявку и покажите подтверждение.
6. В профиле измените имя, покажите историю заявки.
7. Выйдите и войдите администратором. Добавьте, отредактируйте и удалите тестовое объявление, покажите пользователей.
8. Измените статус заявки. Войдите обычным пользователем и проверьте новый статус; отмените заявку.
9. Покажите интерфейс на ширинах 390, 768 и 1440 px, работу меню, форм и карточек.

Таблица всех 19 шагов исходного документа находится в `REQUIREMENTS.md`. **Одно намеренное отличие:** требование показать CSS Grid заменено Flexbox по просьбе пользователя.
