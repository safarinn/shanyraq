# Начни с этого файла

Это проект недвижимости Shanyraq.kz. Для защиты не нужно читать все файлы сразу. Разбери один сценарий, затем переходи к следующему.

## 1. Что показывает сайт — HTML

Открой `public/register.html`. Найди:

```html
<form id="auth-form">
```

Это форма регистрации. В ней есть поля `input` и кнопка `button`.

`id` — имя конкретного элемента для поиска из JavaScript. `class` — название группы элементов для оформления в CSS. `name` — имя поля формы. `required` запрещает оставить поле пустым. `type="email"` проверяет формат почты. `minlength="8"` требует минимум 8 символов в пароле.

**Ответ преподавателю:** «HTML описывает элементы страницы. Формы находятся прямо в HTML, а JavaScript обрабатывает их отправку».

## 2. Как выглядит сайт — CSS

Открой `public/css/style.css`. Там 10 подписанных разделов: основные элементы, формы, меню, баннер, каталог, личные страницы, админка, футер, планшет, телефон.

Пример из проекта:

```css
.property-list {
  display: flex;
  flex-wrap: wrap;
  gap: 20px 2%;
}
.card {
  width: 32%;
}
```

Карточки расположены рядом. Их ширина — 32%, промежутки — 2%. Три карточки помещаются в строку: 32 + 2 + 32 + 2 + 32 = 100%. `flex-wrap` переносит следующую карточку на новую строку.

На планшете `.card` имеет ширину 49%, на телефоне — 100%. Это задано внутри `@media`. CSS Grid в проекте не используется.

**Ответ преподавателю:** «Для расположения элементов использован Flexbox. Media queries меняют ширину карточек и направление блоков на небольшом экране».

## 3. Что происходит после нажатия кнопки — JavaScript

Открой `public/js/auth.js`. Найди `addEventListener('submit', ...)`.

Последовательность:

1. Пользователь отправляет форму.
2. `event.preventDefault()` отменяет перезагрузку страницы.
3. Код читает значения полей через `form.elements`.
4. При регистрации проверяет совпадение паролей.
5. `request()` отправляет данные серверу.
6. При успехе открывается `index.html`; при ошибке появляется сообщение.

`try` — попытаться выполнить действие. `catch` — обработать ошибку. `finally` — выполнить завершающее действие в обоих случаях, например снова включить кнопку.

`async` и `await` нужны, потому что ответ сервера приходит не мгновенно. `await` означает «дождись результата».

## 4. Как работает поиск

Открой `public/js/catalog.js`. Найди `filterProperties()`.

Код читает город, тип недвижимости, цену и поисковый текст. Затем обычный цикл `for...of` проверяет каждое объявление. `continue` пропускает неподходящий объект. `results.push(property)` добавляет подходящий объект в результаты. После проверки `displayProperties()` показывает карточки.

**Ответ преподавателю:** «Поиск не меняет базу. Он выбирает из полученного списка подходящие объекты и обновляет карточки на странице».

## 5. Где сохраняются данные

Браузер отправляет запросы на сервер из `common.js`, через функцию `request()`. Например, маршрут `register` превращается в адрес `/api/register`.

`server.py` принимает запрос, проверяет данные и выполняет SQL. `database.py` открывает SQLite. `schema.sql` содержит четыре таблицы:

| Таблица | Содержание |
|---|---|
| users | Пользователи |
| properties | Объявления |
| favorites | Избранные объекты пользователя |
| bookings | Записи на просмотр |

**Ответ преподавателю:** «Данные находятся в SQLite на сервере. Поэтому после обновления страницы объявления и заявки не исчезают».

## 6. Что делает администратор

Открой `public/admin.html` и `public/js/admin.js`.

- `openEditor()` открывает форму добавления или изменения объекта.
- `loadAdminTables()` получает данные и заполняет таблицы.
- Запрос `admin/property` создаёт или изменяет объявление.
- Запрос `admin/delete` удаляет объявление.
- Запрос `admin/status` меняет статус заявки.

Сервер проверяет роль администратора. Одного скрытия кнопки в браузере недостаточно.

**CRUD:** Create — создать; Read — прочитать; Update — изменить; Delete — удалить.
